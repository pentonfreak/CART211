# Redefining Humanism — 10-page demo

A **real 10-page HTML website** based on the supplied project synopsis, moodboard, site map, and low-resolution wireframes.

## Run
Open `index.html` in your browser. It redirects to `page-01.html`. Or open the folder in VS Code and use the Live Server extension.

## Files
- `index.html` — entry point
- `page-01.html` through `page-10.html` — individual chapters
- `style.css` — global styles, four visual acts, desktop and mobile layout
- `script.js` — navigation, choices, local tab storage, and end reflection

## Page structure
1. The Tiny Blue Dot — animated CSS Earth / cosmic scene
2. What Makes Us Human? — selectable values
3. The Illusion of Choice — styled decision experiment and nudge reveal
4. The Digital Human — visit and click counter, *simulated* profile
5. Who Holds the Power? — compare knowledge asymmetry
6. Faith, Reason, and Morality — three perspectives and ethical choice
7. The Divided Civilization — illustrated fictional world and diplomacy choice
8. The Ideal Civ — 100-point shared civilization budget
9. The Final Frontier — fictional first-contact scenario
10. Redefining Humanism — reflection and restart

## Design language
- Act I: dark minimal cosmic artwork
- Act II: cyan surveillance / futuristic dashboard
- Act III: antique-gold accents and classical philosophical motifs
- Act IV: hopeful cosmic imagery
- Fonts: Anton, DM Sans, IBM Plex Mono via Google Fonts. System fallbacks work without internet.

## Privacy / scope
All interaction state is held in `sessionStorage` within the browser tab. No backend or tracking endpoints. This demo does not access external cookies, a user's name, exact location, or personal files. The profile is an artistic simulation and not a factual inference. No real data is sold or sent anywhere.
