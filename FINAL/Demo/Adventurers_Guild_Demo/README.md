# Adventurer's Guild: The Price of Adventure

A 10-page beginner-friendly HTML, CSS and JavaScript interactive narrative inspired by Shoshana Zuboff's critique of surveillance capitalism.

## Start
Open `index.html` or `page-01.html` in a browser. All pages use one stylesheet and one script. No build or server is necessary.

## Privacy
This demo does not contact a server or read cookies from other websites. When the user chooses the local-memory option, choices are saved in `sessionStorage` in the current tab. The agreement page also allows visitors to proceed without saving; that path has no cross-page memory. The erase buttons clear saved records. Google Fonts can make a font request; remove the `@import` line in `style.css` if offline-only operation is required.

## Files
`page-01.html` through `page-10.html`, shared `style.css`, shared `script.js`, and `index.html` redirect.

## Class connections
Data exhaust / behavioral traces: pages 3-4 and 8. Behavioral prediction and modification: pages 5 and 7. Asymmetry of knowledge and surveillance capitalism: page 9. Reflection and autonomy: page 10. These are conceptual analogies, not claims that the demo performs real surveillance or commercial data sales.
