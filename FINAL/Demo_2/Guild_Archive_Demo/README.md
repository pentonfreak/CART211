# The Adventurer’s Guild — Guild Archive Demo

This is a four-page HTML/CSS-first prototype inspired by a black-and-ivory ornamental interface. Visuals, symbols, and layout are original.

Open `index.html` or `page-01.html` in a browser. You can also use the VS Code Live Server extension.

## Pages
1. Arrival: select a fictional hero name and class.
2. Contract: review an obviously fictional agreement and opt in to the story.
3. Burning Village: choose one of three short story branches and see immediate consequences.
4. Merchant: personalized dialogue and merchandise depend on your previous quest decision.

## Files
- `style.css`: all design, layout and responsive media queries.
- `script.js`: small interactions, conditional dialogue and `sessionStorage` for temporary player choices.

## Privacy and attribution
No backend, API calls or external data sharing. Only locally entered fictional character information and game choices are stored in the browser tab; use "Clear local record" to reset. Google Fonts are optional web resources; the site has system font fallbacks. This project uses original UI graphics; it does not reproduce or use any Project Moon artwork or branding.

## Scope
Pages 1–4 are interactive demo pages; pages 5–10 are not included.
