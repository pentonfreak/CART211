REDEFINING HUMANISM — INTERACTIVE WEBSITE DEMO

HOW TO RUN
1. Extract the ZIP archive.
2. Double-click index.html or open it with a browser.
3. Edit index.html, style.css, and script.js in VS Code.

WHAT IT INCLUDES
- Ten navigable chapters in one HTML page
- Responsive CSS for desktop and mobile (including 480px)
- Pure CSS starfield and illustrated Earth
- Choice buttons, live session stats, sliders, and a personalized reflection
- JavaScript interactions that work without a backend

PRIVACY
The demo stores the current session data in JavaScript memory only. It does not upload session details, store cookies, or request your name or location.
The page imports Google Fonts when online; you can replace them with local/system fonts to make it fully offline.

NOTE FOR CLASS
This is a one-page prototype with ten sections, not ten separate HTML files. If your instructor requires ten individual HTML pages, split sections into separate pages for the final assignment.
